# Obot Sentry for ZCode

This plugin routes ZCode `PreToolUse` decisions to the installed Obot Sentry
binary and asynchronously records `PostToolUse` and `PostToolUseFailure` audit
events. It is distributed as part of the Obot Sentry release asset and does not
modify ZCode's user configuration.

See the release `zcode/README.md` for installation, behavior, and uninstall
instructions.
